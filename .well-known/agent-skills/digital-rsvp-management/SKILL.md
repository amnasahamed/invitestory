# Digital RSVP Management Skill

Use this skill to configure guest tracking, RSVP forms, and automated WhatsApp invite link distribution.

## Key Capabilities

1. **Guest List Import**: Import contact names, phone numbers, and dietary preferences.
2. **Personalized Link Generation**: Generate customized invitation links containing guest names.
3. **Automated WhatsApp Follow-ups**: Send instant confirmations and ceremony reminders.
4. **Attendance Dashboard**: Real-time count of attending, declined, and pending responses.
