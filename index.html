About InviteStory

InviteStory (https://invitestory.in) crafts custom single-event, single-link web wedding invitations designed specifically for Indian weddings. Couples select from 21 culturally-curated templates (Royal Palace, South Indian, Nikah, Walima, Hindu Muhurtham, Ghibli Animation, Beach, Garden), send event details over WhatsApp, and receive a live custom web invite link within 24 hours.

  • One Day, One Wedding Event: Focuses strictly on the main wedding event. Sub-moments (Baraat, Pheras, Jaimala, Nikah ceremony) fit inside the single-day timeline.
  • No RSVP Friction: Removes annoying RSVP forms and WhatsApp confirmation buttons—the invite link acts as an elegant announcement.
  • Built-in Navigation & Sync: Every template features 1-click Google Calendar / .ics event addition and interactive venue directions via Google Maps.
  • Instant WhatsApp Sharing: Fast mobile performance (under 3-5 MB payload) with rich visual cards when shared in WhatsApp chats.
