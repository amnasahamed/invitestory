# Burgundy Reverie personalization

Edit `wedding-data.js` to personalize the invitation. It controls:

- bride and groom names, parents, and short bios;
- wedding date, countdown, date labels, and invitation wording;
- venue name, city, address, directions, and calendar entry;
- the complete event programme;
- RSVP email address, subject, and message.

Leave `rsvp.subject` blank to generate it automatically from the couple's names.
The InviteStory “Try your names” control overrides only the two sample names in the current browser tab; it does not modify this file.
